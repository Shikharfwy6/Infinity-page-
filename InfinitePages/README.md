# Infinite Pages

Jetpack Compose app: unlimited A4 pages, per-page color, text writing, lazy rendering (no lag).

## GitHub se APK banane ka tarika
1. Is poore folder ko ek naye GitHub repo me push karo (branch: main).
2. Repo me **Actions** tab kholo -> "Build APK" chalega (ya "Run workflow" dabao).
3. Build khatam hone par run page ke neeche **Artifacts** se `InfinitePages-debug-apk` download karo.
4. Zip khol kar `app-debug.apk` phone me install karo.
