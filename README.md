# Infinite Pages (Paper Workspace)

Jetpack Compose app:
- Black workspace, do ungli se zoom + pan
- Pages char taraf (upar/neeche/left/right) + se add, pages ek dusre se jude hue
- Per-page colour, grid / lines / dots background
- Text formatting (bold, italic, underline, strike, colour, highlight, size, align, bullets, font)
- Line aur Pen tool (grid par snap)

## GitHub se APK
Files ko repo ke root me upload karo -> Actions tab -> Build APK -> Artifacts me app-debug.apk
